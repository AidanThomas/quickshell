# Phase 4: Compositor Blur

Phase 4 adds persistent, scoped Hyprland blur for Quickshell's translucent island surfaces.

## Persistent configuration

The active Hyprland configuration is generated by Home Manager from:

- `/home/aidant/dev/AidanThomas/hyprland-config/lua/options.lua`
- `/home/aidant/dev/AidanThomas/hyprland-config/lua/rules.lua`

The Home Manager configuration was rebuilt with `switch-home`, and Hyprland was reloaded successfully.

## Applied blur settings

```lua
blur = {
    enabled = true,
    size = 8,
    passes = 2,
    new_optimizations = true,
    noise = 0.02,
    contrast = 0.9,
    brightness = 0.85,
    vibrancy = 0.12,
    vibrancy_darkness = 0.1,
}
```

The layer rule is scoped to the exact `quickshell` namespace:

```lua
hl.layer_rule({
    name = "quickshell-blur",
    match = { namespace = "^quickshell$" },
    blur = true,
    blur_popups = true,
    ignore_alpha = 0.1,
})
```

The alpha threshold prevents fully transparent panel gaps from producing a visible blurred strip while allowing the substantially more opaque islands and popup surfaces to receive blur.

## Verification

- `hyprctl configerrors` returned `ok`.
- Live values report blur size 8, passes 2, noise 0.02, brightness 0.85, and vibrancy 0.12 as explicitly set.
- Transparent areas between islands remain visually clear.
- The bar renders correctly over the current bright, detailed wallpaper.
- Quickshell auxiliary layer surfaces share the namespace and inherit the rule.
- DP-1 has the Quickshell layer and blur treatment.
- DP-3 has no Quickshell layer by current design, so there is nothing to blur on that monitor.
- A true fullscreen client covers the bar entirely under the current compositor behavior. The fullscreen test was explicitly reverted.

Lightweight process readings during normal operation:

- Hyprland: approximately 1.1% CPU.
- Quickshell: approximately 0.7% CPU.
- Cava: approximately 1.0% CPU.

These point-in-time readings are not a formal benchmark, but no obvious performance regression or animation degradation was observed.
